Why the app itself is not live here. GitHub Pages serves static files only. The Custodia app is a Next.js frontend plus a Python backend that runs the search engine, a large embedding model, a vector database, and the SAHMK market-data feed — none of which can run on Pages. To run the full app, host the frontend (e.g. Vercel) and the backend (a server host) separately, or run it locally: start the backend on 127.0.0.1:8000 and the frontend on 127.0.0.1:3000.
